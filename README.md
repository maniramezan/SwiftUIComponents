# SwiftUIComponents

Reusable SwiftUI building blocks targeting macOS 15, iOS 18, and Mac Catalyst 18. The package exposes modular views (such as `MenuPicker`) that can be composed in client apps through Swift Package Manager.

## Getting Started
- `swift build` compiles the library.
- `swift test` runs the XCTests in `Tests/SwiftUIComponentsTests`.
- Open `Package.swift` in Xcode 16 for previews or to integrate the package into an app project.
